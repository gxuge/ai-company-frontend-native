## 3. 本轮字段口径
- `role_name`：若匹配 `角色 + 长时间戳` 占位格式，则置空后再参与模板变量拼接。
- `occupation`：若为“待定职业”占位值，则置空后再参与模板变量拼接。
- `background_story`：若为“这是一个等待你继续完善背景设定的角色。”占位值，则置空后再参与模板变量拼接。

## 4. 调用时机与回退
- 调用时机：
  - `POST /sys/ts-roles/one-click-setting`：产出角色核心字段。
  - `POST /sys/ts-roles/one-click-image`：生成形象前拼接模板变量。
- 失败回退：
  - 若模型返回异常，保持现有兜底链路（继续用 renderedPrompt 生成图），不影响主链路可用性。
